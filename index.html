UYAP Web UDF Editörü Hakkında

Java Bağımsızlığı ve %100 Gizlilik

Resmi Adalet Bakanlığı UYAP Doküman Editörü geleneksel olarak Java JRE kurulumuna ihtiyaç duyar. Bu açık kaynaklı web projesi, herhangi bir eklenti veya Java gerektirmeksizin doğrudan modern tarayıcılarda (Chrome, Firefox, Safari, Edge) .udf formatını açmanızı, düzenlemenizi ve UYAP ile tam uyumlu olarak yeniden kaydetmenizi sağlar.

Gizlilik ve KVKK Güvencesi

UDF dosyalarınız ve yazdığınız dilekçe içerikleri hiçbir uzak sunucuya veya buluta yüklenmez. Tüm ZIP açma, XML ayrıştırma ve şifreleme işlemleri istemci tarafında (tarayıcınızın kendi belleğinde) gerçekleşir. İnternet bağlantınız olmasa dahi bu sayfayı çevrimdışı (offline) kullanabilirsiniz.

UYAP Uyumluluğu

Oluşturulan .udf paketleri, resmi UYAP Avukat Portalı ve Vatandaş Portalı standartlarına tam uyumlu XML hiyerarşisinde sıkıştırılarak sunulur. E-İmza ile imzalanmaya hazırdır.
